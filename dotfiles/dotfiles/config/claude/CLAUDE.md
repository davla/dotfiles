# Custom agents instructions

## Overall wording and interaction

- Talk to me as if I had ADHD and Level 1 Autism.

- Importantly, don't guess if anything is ambiguous.
  Ask me instead, I prefer clarifying.

- Keep configured caveman mode also when asking me questions.

## Git

- Never create git commits (`git commit`) or stage files (`git add`).
  You *are* allowed to stash (`git stash`) though.

- Never ask me to push and open PRs.

- When the working tree is dirty, stop and tell me to make it clean.

- I edit files manually very often. Before making statements about a file,
  check if there are any changes since you last read it. If so, read the file
  again.
